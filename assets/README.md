# Branding assets

Senaflix branding is allowed to be shown publicly with this project.

Binary logo / splash assets are intentionally kept separate from the theme code when publishing through automated tooling that cannot safely write binary repository files.

Recommended public assets:

- Senaflix standalone emblem (transparent PNG)
- Senaflix horizontal logo (transparent PNG)
- Senaflix 1920×1080 splash / home image

Do not place private server screenshots or deployment information in this directory.
